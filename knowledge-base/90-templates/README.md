# Reusable iOS planning templates

Use the smallest template that makes the route and evidence explicit. These
are planning artifacts, not proof that a target builds or that a capability
works on a physical device.

- [Native iOS design brief](design-brief.md) — general product and surface brief.
- [iOS 27 native design brief](ios27-native-design-brief.md) — HIG platform matrix, Liquid Glass spatial hierarchy, accessibility, and SDK gates.
- [On-device AI feature brief](ai-feature-brief.md) — model route, validation, privacy, and evaluation.
- [iOS 27 performance and on-device proof](ios27-performance-and-on-device-proof.md) — workload, MetricKit, processing location, and claim evidence.
- [Target-aware feature scaffold](target-aware-feature-scaffold.md) — vertical-slice target/module/state plan.
- [Xcode target and module plan](xcode-target-and-module-plan.md) — project graph, configuration, and release ledger.
